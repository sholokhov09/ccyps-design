CCYPS Design Toolkit — Coherent Minimal UI iteration

Design system constraints applied
- 1 typeface: Alexandria
- 3 font sizes only: 40px / 16px / 11px
- 3 font weights only: 400 / 500 / 700
- 2 text colors only: #101010 / #8A8A8A
- 8px base spacing grid
- 12-column desktop grid, 4-column mobile grid
- 384px tool rail aligned to the 8px grid
- square geometry, no decorative radius
- light-grey hairlines
- light-grey hover and active states
- page-specific actions remain local to each sidebar

Files
- index.html — landing page
- pattern.html — pattern generator
- logo.html — logo generator
- assets/shared.css — global tokens, header, navigation, shared controls
- assets/landing.css — 12-column landing layout and cards
- assets/pattern.css — pattern tool layout and controls
- assets/logo.css — logo tool layout and controls

Functionality
- Existing pattern shader, canvas behavior, exports, logo assets, and logo export/copy logic are preserved.
